# 安装 / 卸载

## 前置

| 需要 | 说明 |
|---|---|
| Windows 10/11 | 桌宠运行在桌面层 |
| DeepSeek Harness + dsh-pet | 提供桌宠运行环境（独立模式即可） |
| Python 3.10+ | 只在你自己做素材时需要 |
| Electron | 只在跑账本气泡时需要，dsh-pet 自带的那份就能用 |

## 安装

### 1. 放配置

```powershell
$root = "$env:USERPROFILE\.dsh\dsh-pet"
mkdir "$root\pet\naiwa-animation" -Force
copy .\pet-pack\naiwa-config.json "$root\pet\naiwa-config.json"
```

### 2. 放素材

把你自己的 `.webm` 放进：

```
%USERPROFILE%\.dsh\dsh-pet\pet\naiwa-animation\
```

文件名必须和 `naiwa-config.json` 里引用的动画名一致（例如 `奶蛙-站立呼吸.webm`）。

检查有没有漏：配置里引用的每个名字都要有同名 webm。

### 3. 注册宠物

编辑 `%USERPROFILE%\.dsh\dsh-pet\main-config.jsonc`，在 `pets` 数组里加一项（见 README）。

**改完先备份！** 出问题能恢复：

```powershell
copy "$root\main-config.jsonc" "$root\main-config.jsonc.bak"
```

### 4. 重启

关掉桌宠（或双击 `关闭桌宠.bat`），再打开。

### 5. 验证

```powershell
Invoke-WebRequest "http://127.0.0.1:3080/dsh-pet-7340/config" -UseBasicParsing |
  Select-Object -ExpandProperty Content | Select-String "naiwa"
```

能看到 `naiwa` 就说明种类加载成功。

## 卸载

```powershell
$root = "$env:USERPROFILE\.dsh\dsh-pet"
Remove-Item "$root\pet\naiwa-config.json" -Force
Remove-Item "$root\pet\naiwa-animation" -Recurse -Force
# 再把 main-config.jsonc 里 naiwa 那一项删掉
```

然后重启桌宠。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 看不到宠物 | 配置放错目录（放根目录了） | 必须放 `dsh-pet\pet\` |
| 宠物在但没有动画 | 素材在 `naiwa-animation\webm\` 里 | 直接放 `naiwa-animation\` |
| 动作名报 unknown-animation | 文件名和配置里的名字不一致 | 逐个核对 |
| 素材发黑块 | webm 编码没带 alpha | 重编码，见 README 的「坑」 |
| 宠物被别的窗口挡住 | 桌宠是桌面层窗口 | 最小化挡它的窗口 |
